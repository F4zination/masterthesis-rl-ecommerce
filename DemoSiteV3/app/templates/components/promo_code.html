{# Promo-code redemption box (cart + checkout). Participants shown the discount_banner widget are told the code SAVE10 but previously had nowhere to type it, which left them hunting for a promo field. This box is the redemption surface only: it accepts nothing but the code the widget advertises, so a session that never saw that arm cannot self-serve the discount, and the arm's measured value is unchanged. Manual redemption emits `discount_code_entered`, which carries no reward — the discount arm must only be credited for its own widget interaction. #}
